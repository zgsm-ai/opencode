<common_commands>
### agent-git 常用命令

```bash
# 查看最近的提交记录
agent-git --no-pager log -5

# 查看指定 agent 的提交
agent-git --no-pager log --author="{{author_example}}"

# 查看某次提交的详细修改
agent-git --no-pager show <commit-id>

# 查看是否有未提交的修改
agent-git status -s

# 查看文件差异
agent-git --no-pager diff
```
</common_commands>
