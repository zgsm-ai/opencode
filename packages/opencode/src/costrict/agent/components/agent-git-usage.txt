## Agent-Git 使用说明

Agent-git 是一个独立的 Git 仓库（位于项目根目录的 `.agent-git/`），用于跟踪 agent 的修改历史。

### 常用命令

```bash
# 查看最近的提交记录
agent-git --no-pager log -5

# 查看指定 agent 的提交
agent-git --no-pager log --author="AgentName"

# 查看某次提交的详细修改
agent-git --no-pager show <commit-id>

# 查看是否有未提交的修改
agent-git status -s

# 查看文件差异
agent-git --no-pager diff
```

### 提交代码

```bash
# 添加修改的文件
agent-git add <file-path>   # 或 agent-git add -A

# 提交（使用你的 agent 代号作为 author）
agent-git commit --author="{{AGENT_NAME}} <agent@local>" -m "<简要描述>

<详细说明>"

# 检查提交是否成功
agent-git status --porcelain
```

### Commit 信息格式

- 第一行：简洁的概括性标题（方便 `agent-git log --oneline` 浏览）
- 后续行：详细说明（可选）

**示例**:
```
[SubCodingAgent-1] 实现用户认证模块

- 添加 login() 和 logout() 方法
- 集成 JWT token 验证
- 修改相关测试用例
```
