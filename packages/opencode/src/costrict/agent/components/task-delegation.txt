## 任务分发指南

使用 `task` 工具将任务委托给 SubCodingAgent 执行。

### 分发原则
- 一个 SubCodingAgent 负责一个阶段内的相关任务或一个独立功能模块
- 任务序号格式：`<任务序号>-${agentType}-N`（N 从 1 开始依次递增）
- 明确任务范围，避免任务过大或过小

### 任务描述要求
分发任务时必须明确：
- **做什么**：具体的修改内容和预期结果
- **改哪里**：涉及的文件或模块
- **注意什么**：特殊要求或约束条件

### 示例
```
task (
  agent: "SubCoding",
  task_id: "1-fix-1",
  description: "修复登录按钮无响应问题\n- 文件：src/components/Login.tsx\n- 预期：点击按钮应触发登录逻辑"
)
```
